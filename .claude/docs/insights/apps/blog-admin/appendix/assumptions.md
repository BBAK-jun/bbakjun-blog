## 비용 관련 가정 (Cost Assumptions)

### 개발 비용

- **개발자 시간당 비용**: $50/hour (시장 평균가)
  - 범위: $40-$60/hour (시니어/주니어 차이)
  - 출처: 2024년 개발자 연봉 조사 (Stack Overflow, Glassdoor)
- **월간 개업 일수**: 20일 (주 5일 × 4주)
- **일일 작업 시간**: 8시간
- **연간 개발 비용**: $96,000 (1인 기준)

### 인프라 비용

- **Vercel Blob API**: $0.01/1,000 calls
  - 실제 비용: Vercel 프리 티어 제한 확인 필요
  - 월 2,000회 초과 시 $20/월 과금
- **PostgreSQL (Neon)**: $20/월 (기본 플랜)
  - Serverless: $0.00025/credit
  - 평균 월 사용량: 100,000 credits
- **Vercel Pro**: $20/월
  - 빌드 시간 100배 증가
  - 무한 대역폭
  - 100개 Edge Function

### API 호출 비용

- **Vercel KV (Redis)**: $0.15/100,000 commands
- **Vercel Functions**: $0.30/100GiB-seconds
- **Vercel Edge**: $0.60/100GiB-seconds

## 생산성 향상 가정 (Productivity Improvement Assumptions)

### FSD 아키텍처 효과

- **신규 기능 개발 시간 단축**: 35% (3일 → 2일)
  - 최적: 50% (3일 → 1.5일)
  - 최악: 20% (3일 → 2.4일)
- **디버깅 시간 감소**: 50%
  - 원인: 명확한 레이어 분리로 영향 범위 축소
- **코드 리뷰 시간 단축**: 40%
  - 원인: 표준화된 구조와 패턴

### 타입 세이프 RPC 효과

- **API 관련 버그 감소**: 80%
  - 컴파일 타임 오류 검출
  - 런타임 타입 불일치 해결
- **API 문서 유지보수**: 100% 비용 절감
  - OpenAPI 자동 생성
- **프론트-백엔드 협업 시간**: 30% 단축

### 자동화 효과

- **수동 배포 시간**: 월 8시간 → 0시간
- **마이그레이션 관리**: 월 4시간 → 1시간
- **환경 변수 관리**: 월 2시간 → 0.5시간

## 성장 및 확장 가정 (Growth & Scaling Assumptions)

### 트래픽 증가

- **연간 트래픽 증가율**: 30%
  - 컨텐츠 양 증가
  - 사용자 기반 확대
- **API 호출 증가**: 현재 2,000회/월 → 2,600회/월 (1년 후)
- **동시 사용자**: 현재 10명 → 50명 (1년 후)

### 사용자 확장

- **관리자 계정**: 현재 1개 → 5개 (멀티 테넌트 고려)
- **권한 레벨**: 3단계 (Admin, Editor, Viewer)
- **기능 사용률**: 현재 60% → 85% (1년 후)
